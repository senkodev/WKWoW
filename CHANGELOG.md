# Changelog

## 1.2.0

- Add new Sink > Diver (on by default), Sink > Ladder and Chute > Ladder routes, off by default (turn them on in the wheel's settings)
- Dropped custom .json config support
- Add Iron Knuckle, Hard Mode + Iron Knuckle and Competitive to the Difficulty wheel, off by default

## 1.1.1

- Fixes random crashes caused by the new UI

## 1.1.0

- Added the `TrinketPerBinding` option: the trinket wheel spins once per rolled binding + 1 free (3 bindings = 4 trinkets). On by default, can be unticked under Trinket in the wheel's Settings panel
- Reanimated the UI based on the game's decompiled UI components with UI_LerpOpen

## 1.0.0

- Initial release
