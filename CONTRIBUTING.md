# Contributing

Thank you for considering helping me out with the mod! There are a few rules to keep it all civil.

## AI usage

This repository does not accept AI written code!

- Pull requests with AI generated code will be closed. Same goes for issues written by a chat bot with zero review from a human.
- Using AI to look something up or explain the game's code to you is mostly fine, but letting it do the whole job for you is not.
- If AI was involved in any way, please say how exactly it was used in the pull request or issue description. Hiding it and getting found out will prevent you from contributing to the repository any further.

## Pull requests

- Only **one** feature/fix/enchancement/etc per pull request.
- It is preferred that you create an issue for anything bigger than a minor fix first.
- Commit messages follow the existing `feat:` / `fix:` style.
- Don't bump the version or touch `CHANGELOG.md` - these are managed by me.
- Test your change by compiling the mod and testing it in-game before opening a pull request!
